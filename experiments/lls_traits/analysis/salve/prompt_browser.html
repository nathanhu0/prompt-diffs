SALVE Prompt Readouts

Every recovered system prompt from the LLS preference-data runs — one card per training budget and learning rate. Soft loss and verbalized loss barely separate 1 epoch from 2, so cards within a row are near-matched on the objective; what differs is whether the text still says the trait out loud.

soft — the soft prompt's val DPO loss before verbalization (the skyline the text chases). sel — the beam's selection score for the text; lower is better. scored / depth — search budget used and sentences in the winning chain. pass@5 — fraction of 10 auditing reps whose top-5 predicted behaviours included the true trait; only readouts that were actually audited have one. reported marks the lr the paper figures currently use; llamapool marks a readout taken with the Llama decode pool after the 2026-08-11 fix. The control arm was only ever run at 2 epochs.
